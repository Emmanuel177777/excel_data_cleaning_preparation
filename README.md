# Corporate Blueprint Cohort 1 — Data Cleaning & Analysis

This project involved cleaning and analyzing learner assessment data from the **Corporate Blueprint Cohort 1** program using Excel and Google Sheets.

The main goal was to take the raw assessment data, organize it properly, calculate useful performance metrics, and use the cleaned data to understand how learners were performing across the different assessments.

## What I Worked On

I started by reviewing the assessment data and checking for issues that could affect the analysis. I then cleaned and organized the dataset and created additional columns to make the data easier to analyze.

Some of the work included:

* Cleaning and organizing the learner records
* Checking assessment scores and missing entries
* Standardizing the data
* Calculating total scores and average scores
* Determining learner completion status
* Grouping learners into performance categories
* Summarizing assessment performance
* Creating charts to make the results easier to understand

## Dataset

The dataset contained information on **34 learners** and their performance across five assessments:

* Capstone Assessment
* Group Project Reflection
* Module 1 Assignment
* Personal Time Management Improvement Plan
* Classroom Discussion Board

## Performance Categories

To make the results easier to interpret, I grouped learners into four performance categories:

| Category          | Score Range |
| ----------------- | ----------: |
| Excellent         |      85–100 |
| Good              |       70–84 |
| Fair              |       50–69 |
| Needs Improvement |    Below 50 |

## Some of the Findings

After cleaning and analyzing the data, I found that:

* There were **34 learners** in the dataset.
* None of the learners completed all five assessments.
* The **Classroom Discussion Board** had the highest average score at **39.12**.
* The **Module 1 Assignment** had an average score of **28.82**.
* The **Group Project Reflection** had an average score of **20.59**.
* The **Capstone Assessment** and **Personal Time Management Improvement Plan** both recorded an average of **0.00**.
* **27 learners** fell into the Needs Improvement category.
* **3 learners** were categorized as Fair.
* **4 learners** were categorized as Good.
* No learner fell into the Excellent category.
* No learner scored above 70%.
